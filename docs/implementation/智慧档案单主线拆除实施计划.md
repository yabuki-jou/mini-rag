# 智慧档案单主线拆除实施计划

## 1. 目标与边界

本计划落实 DEC-022：当前产品主线收敛为智慧档案 V1、FR-039 档案问答和 FR-042 项目档案助手。删除没有 Vue 展示入口的通用知识库问答、普通 Chat 和企业制度 Agent 的公开运行代码，但不删除或迁移现有 PostgreSQL、SQLite Checkpoint、Chroma Collection、原文件或 Alembic 历史。

保留 `KnowledgeBase`、`Document`、`AgentSession`、`AgentToolCallLog` 及 `AgentType.POLICY`。前两者仍是项目档案数据底座；后两者继续服务 FR-042；`POLICY` 仅用于兼容历史行并确保旧会话不能进入档案入口。

## 2. 执行规则

- 后端和 Vue 均在 `codex/archive-only-scope` 分支实施。
- 遵循 RED → GREEN → REFACTOR；每个切片先形成可观察的失败测试。
- 只显式暂存本计划内文件，不使用全量暂存，不覆盖用户既有改动。
- 迁移历史只验证不改写；不新增删表迁移，不执行数据或向量清理。
- Mock 只证明确定性契约；本轮不修改 FR-039/FR-042 的语义质量算法，既有固定集结论只作为回归边界，不能由单元测试替代。

## 3. 实施切片

### P00：保存现有成果并建立分支

1. 在 `codex/policy-rag-preservation` 验证并分别提交制度 Collection 重建脚本及测试、未标定距离阈值示例。
2. 推送保护分支。
3. 后端和 Vue 分别创建 `codex/archive-only-scope`。
4. 写入本计划和 DEC-022。

### P01：冻结下线契约

1. RED：证明五类旧路径仍出现在 OpenAPI，并可命中旧 Router。
2. GREEN：从应用注册中移除旧 Router。
3. 验收：旧路径从 OpenAPI 消失并返回 FastAPI 默认 `404`；不注册 `410` 或占位路由；项目档案助手接口保持存在。

### P02：拆除后端旧运行代码

1. RED：包边界测试禁止旧 Router、制度 Agent、通用 RAG、普通 Chat 和旧评测包重新出现。
2. 删除旧运行模块及其正向功能测试；将 FR-042 仍需的 `MessageRole` 和工具日志响应 DTO 移入档案助手契约。
3. 删除旧 Chat ORM 映射，但允许历史迁移中的 `chat_sessions`、`chat_messages` 不再映射为当前 SQLModel。
4. 移除只服务旧通用 RAG 的配置、示例项、脚本和制度评测入口。
5. 保留历史 `POLICY` 枚举与数据库约束，验证档案入口仍拒绝历史制度会话，项目删除不误清理无项目绑定的历史线程。

### P03：清理 Vue 残留

1. RED：API 对象当前仍暴露知识库、普通文档、检索和 Chat 方法。
2. 删除旧 API 方法、旧本地会话作用域、未使用类型及正向测试。
3. GREEN：API 表面不再暴露旧方法；智慧档案页面、路由和 FR-042 交互不变。

### P04：文档与发布收口

1. 更新当前 AGENTS、README、学习计划、需求、架构、数据库、接口设计和目录说明。
2. 将制度 Agent 的实施、导览、演示与评测资料迁入历史归档；历史资料不作为当前实现依据。
3. 新增单主线发布说明并更新 handoff。
4. FR-042 继续拒绝历史 `POLICY` 会话，但当前文档不再描述双向运行入口。

## 4. 验收门

后端必须通过：下线路由契约、保留路由契约、包边界、FR-039、FR-042、项目删除兼容测试、全量 `pytest`、`compileall app tests scripts evals`、Alembic head 和 Markdown 链接检查。

Vue 必须通过：API 表面契约、完整测试、类型检查和生产构建。

最后执行本地真实代理冒烟：登录、项目、档案目录、FR-039、FR-042 历史和工具日志。若本地服务或凭据不可用，必须记录实际阻塞，不得把静态测试表述为真实闭环通过。

## 5. 完成标准

- 当前源码不再注册或导入旧通用 RAG、普通 Chat 和制度 Agent。
- 旧 API 从 OpenAPI 消失并返回默认 404。
- 数据、迁移和历史兼容枚举保持不变。
- 智慧档案与 FR-039/FR-042 回归通过。
- 当前文档只把智慧档案描述为正式产品主线。
