# 智慧档案单主线：本地演示版说明

本说明对应后端与相邻 Vue 工作台已合并到 `main` 的智慧档案主线。它是本地演示与学习基线，不代表云端或公开多用户部署。

## 可展示能力

- 智慧档案 V1：项目与文档生命周期、四格式解析、人工确认、正式索引、档案目录、清单和脱敏审计。
- FR-039：按当前项目检索正式档案，提供带原文证据的问答与无据拒答。
- FR-042：项目范围内的只读档案助手，提供跨轮对话、工具调用观测，以及刷新后自动恢复最近一次会话。

完整演示入口与本地启动方法见[项目 README](../../README.md)；测试与人工验证边界见[验收报告](../review/验收报告.md)。

## 不再提供的公开能力

通用知识库、普通 Chat 和制度 Agent 已从当前公开 API 与运行代码下线。旧的 `/knowledge-bases`、`/chat-sessions` 和非项目范围的 `/agent-sessions` 路径不保留兼容入口；项目档案助手使用 `/projects/{project_id}/agent-sessions` 路径组。

历史 PostgreSQL 表与数据、SQLite Checkpoint、Chroma Collection、原文件和 Alembic 迁移仅作兼容或追溯保留；保留数据不等于保留旧 API。历史 `POLICY` 会话不能从档案入口进入。旧制度 Agent 资料位于[归档目录](../archive/legacy-policy-agent/)。

## MVP 限制

- 刷新后仅自动发现并恢复当前项目最近一次档案助手会话；不提供完整会话管理。
- 历史消息不恢复旧回答的引用卡片，未完成的异常轮次不显示。
- PostgreSQL 与 Checkpoint SQLite、文件和 Chroma 之间没有跨存储原子事务。
- 本地测试、真实模型固定集评估与浏览器联调各自证明其范围；不能据此宣称生产部署或所有问题的回答质量。
