# 智慧档案单主线发布说明

## 发布范围

本次发布将后端正式能力收敛为：

- 智慧档案 V1：项目、清单、文档生命周期、人工确认、正式目录和审计；
- FR-039：项目正式档案检索与带原文证据问答；
- FR-042：服务端绑定项目范围的项目档案助手，支持目录/证据只读工具、多轮历史和脱敏工具记录。

## 下线范围

通用知识库、普通 Chat 和制度 Agent 不再属于当前产品能力。以下路径从 OpenAPI 移除，访问返回默认 `404`，不保留 `410` 或占位兼容入口：

- `/knowledge-bases` 及其文档、检索测试子路径；
- `/chat-sessions` 及其消息子路径；
- `/agent-sessions` 及其消息、历史和工具日志子路径。

项目档案助手仍使用 `/projects/{project_id}/agent-sessions` 路径组。

## 数据兼容边界

本次收敛不删除或迁移 PostgreSQL 历史表与数据、SQLite Checkpoint、Chroma Collection、原文件或 Alembic 迁移。`KnowledgeBase`、`Document` 继续作为项目档案底座；`AgentType.POLICY` 仅保留为历史行兼容值，项目档案助手入口必须拒绝 `POLICY` 会话。

保留历史数据不等于保留旧 API 或运行能力。历史制度 Agent 资料位于
[`docs/archive/legacy-policy-agent/`](../archive/legacy-policy-agent/)，只用于追溯。

## 验收边界

发布前应验证旧路径不出现在 OpenAPI、访问返回默认 `404`，并验证项目、档案、FR-039 和 FR-042 的保留契约不变。真实 PostgreSQL、Chroma、文件和 DeepSeek 联动结果必须以当前验收报告为准，不能用历史制度 Agent 评测替代。
