```powershell

python -m alembic upgrade head
python run.py
python -m pytest -q
python -m compileall -q app tests scripts evals
```

## 5. 配置与运行约束

- 配置来自环境变量及项目根目录 `.env`；模板为 `.env.example`。
- `DATABASE_URL` 必须是 `postgresql+psycopg://`；业务库不再允许 SQLite。
- SQLite 仅保存 LangGraph Checkpoint；测试也会使用隔离 SQLite。
- Chroma、BGE 与 DeepSeek 的参数均通过配置提供；真实密钥不应进入仓库。
