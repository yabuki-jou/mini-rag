# 外部集成

当前正式集成服务只支撑智慧档案 V1、FR-039 和 FR-042。旧通用 RAG、普通 Chat、制度 Agent 的历史配置、表和 Collection 不再有公开运行入口；保留它们不代表当前能力仍可用。

## 1. 集成清单

| 系统 | 类型 | 用途 | 认证/配置 | 关键性 | 证据 |
|---|---|---|---|---|---|
| PostgreSQL | 业务数据库 | 用户、文档、Agent、归档业务事实 | `DATABASE_URL` | 高 | `app/db.py`、`migrations/` |
| SQLite | 本地状态库 | FR-042 LangGraph Checkpoint | `AGENT_CHECKPOINT_FILE` | 中 | `app/agents/archive/runtime.py` |
| 本地文件系统 | 文件存储 | 原始上传文件、日志、解析快照规划 | `FILE_STORAGE_DIR`、`LOG_FILE` | 高 | `app/services/infrastructure/files.py` |
| Chroma | 向量数据库 | 正式档案 Chunk 的写入、检索、精确删除 | host、port、tenant、database、collection | 高 | `app/services/infrastructure/chroma.py`、`app/services/archive/` |
| 本地 BGE | 模型 | 文档和查询 Embedding | 模型路径、设备、维度 | 高 | `app/services/infrastructure/ai_models.py` |
| DeepSeek | 外部 LLM API | FR-039 证据问答与 FR-042 档案助手 | API Key、URL、模型 | 中 | `app/services/infrastructure/ai_models.py` |

## 2. 数据边界

| 存储 | 事实来源 | 访问层 | 主要风险 |
|---|---|---|---|
| PostgreSQL | 业务身份、状态、审计和归档领域 | SQLModel + Alembic | Chroma/文件系统之间无分布式事务 |
| SQLite | Agent 图执行状态和消息 Checkpoint | `AdminAgentRuntime` | 单机文件锁与多实例扩展限制 |
| 文件系统 | 原文件 | `infrastructure/files.py` | 删除与数据库状态需要补偿 |
| Chroma | 可重建的正式档案 Chunk/向量索引 | `services/archive/` | 只有人工确认后的档案进入正式范围 |

## 3. 密钥与配置

- `.env` 由 `Settings` 读取，`.env.example` 是可提交模板；真实 `.env` 被忽略。
- DeepSeek API Key 使用 `SecretStr`，客户端构造时会取出真实值用于连接；Chroma 使用 host、port、tenant、database 和 collection 配置，不配置 Token/SecretStr。
- 未发现密钥轮换、Secret Manager 或生产多环境配置机制。[TODO]

## 4. 可靠性行为

- FR-042 Agent 只对约定的超时和连接失败执行受控重试；参数、权限和拒答不重试。
- 文件删除和档案删除具有幂等/补偿逻辑；Chroma 写入、检索与 DeepSeek 错误转换为 `AppError`。
- 未发现 DeepSeek、Chroma 或 BGE 的统一 timeout、熔断器、限流或后台队列。[TODO]

## 5. 可观测性

- HTTP 请求使用 request ID；档案处理、检索和 Agent 工具记录资源 ID、数量和耗时。
- Agent 工具日志保存脱敏摘要；不保存档案全文或内部异常正文。
- 未发现 Metrics、分布式 Trace、集中日志或告警集成。[TODO]
