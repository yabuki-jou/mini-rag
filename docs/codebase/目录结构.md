# 文件结构

## 1. 顶层结构

| 路径 | 当前职责 | 证据 |
|---|---|---|
| `app/` | FastAPI 应用、领域模型、服务、Agent | 源码目录 |
| `migrations/` | Alembic 前向迁移 | `migrations/env.py`、`migrations/versions/` |
| `tests/` | pytest 单元、路由、迁移与契约测试 | `tests/test_*.py` |
| `scripts/` | 虚构验收资料生成脚本 | `scripts/generate_archive_v1_eval_data.py` |
| `docs/` | 需求、架构、数据库/API 设计与学习记录 | `docs/*.md` |
| `evals/` | 按业务域组织的当前评测入口、数据集、评审器与说明 | `evals/policy_agent/` |
| `pixie_qa/` | Pixie 本地运行状态与忽略的结果目录，不再保存评测源码 | `pixie_qa/results/` |
| `run.py` | 本地 Uvicorn 启动入口 | `run.py` |
| `compose.yaml` | 本地容器编排 | `compose.yaml` |

`data/`、`logs/`、`.pytest_cache/` 和 `.idea/` 不是应用源码边界。

## 2. 入口点

- 运行入口：`run.py` 导入 `app.main:app` 并启动 Uvicorn。
- 组合根：`app/main.py` 安装日志、中间件、异常处理器、路由，并在 lifespan 中执行 Alembic upgrade。
- 没有独立 Worker、CLI 或后台队列入口。[TODO]

## 3. 模块边界

| 目录 | 应包含 | 不应包含 |
|---|---|---|
| `app/routers/` | HTTP 路径、请求/响应、依赖注入 | 解析、向量、模型编排和跨存储事务 |
| `app/dependencies/` | Session、`X-User-ID`、资源所有权和 `ProjectContext` | 领域状态迁移 |
| `app/schemas/` | Pydantic HTTP 契约 | SQLModel 持久化逻辑 |
| `app/models/` | SQLModel 表、枚举、数据库约束 | HTTP 输入模型和服务流程 |
| `app/services/` | 应用流程、事务、文件、解析、Embedding、Chroma、DeepSeek 适配 | FastAPI Response 对象 |
| `app/agents/` | LangGraph 状态、Prompt、只读工具、运行时观测 | 数据库 Session 持久化 |
| `app/core/` | 配置、日志、错误和评测钩子 | 具体业务流程 |

现有旧路由中的用户/知识库创建和列表、文档列表仍直接使用 Session；这是上述目标边界的已知例外，详见 `关注事项.md`。
新建的 `app/routers/projects.py` 已遵循 `Router → project/management.py` 与档案业务服务分层。

## 4. 命名与组织规则

- Python 文件、函数、变量、数据库字段使用 `snake_case`。
- 类、枚举、Pydantic/SQLModel 类型使用 `PascalCase`。
- Router 与 Service 按资源或能力命名，如 `documents.py`、`archive/documents.py`。
- API 契约使用 `Create`、`Request`、`Read`、`Response` 后缀。
- 使用绝对 `app.*` 导入；services 子包的 `__init__.py` 只声明职责，不集中重导出业务函数。
