# 测试说明

## 1. 测试栈与命令

- 主框架：pytest 9.0.2。
- 断言/Mock：普通 `assert`、`unittest.mock`、`pytest.MonkeyPatch`、FastAPI TestClient。

```powershell
python -m pytest -q
python -m pytest -q tests/test_postgres_migrations.py  # 需专用空库 POSTGRES_TEST_URL
python -m compileall -q app tests migrations scripts
```

本轮完成 P04.2 清单项 CRUD/派生状态后的最新完整回归结果为 `130 passed, 1 skipped, 16 warnings`；跳过项是未配置 `POSTGRES_TEST_URL` 的专用 PostgreSQL 自动化迁移测试。

## 2. 测试布局

- 新增测试目录与被测代码层一一对应：`app/routers/` 对应 `tests/routers/`，`app/schemas/` 对应 `tests/schemas/`；无关历史测试暂不因目录整理移动。
- `test_document_*`、`test_chat_*`、`test_retrieval.py` 覆盖旧 RAG 基座。
- `test_admin_graph.py`、`test_agent_router.py`、`test_read_tools.py` 覆盖只读 Agent。
- `test_migrations.py`、`test_postgres_migrations.py`、`test_schema_comment_contract.py` 覆盖迁移与模型/注释契约。
- `test_archive_parser_spike.py`、`test_archive_v1_evaluation_data.py`、`test_project_context.py` 覆盖智慧档案 P01～P03 基础；`tests/routers/test_projects.py` 覆盖 P04.1 项目 API；`tests/schemas/test_checklist_schemas.py` 与 `tests/routers/test_projects_checklist.py` 覆盖 P04.2 清单项 API。

## 3. 范围矩阵

| 范围 | 覆盖 | 说明 |
|---|---|---|
| 单元 | 是 | Parser、Chunk、检索、错误转换、数据映射与状态分支 |
| 路由集成 | 部分 | Chat、Document 删除、Agent 路由使用 TestClient 和依赖替换 |
| SQLite 迁移 | 是 | 临时 SQLite 验证迁移顺序和约束；不代表生产方言语义 |
| PostgreSQL 迁移 | 可选 | 仅在显式提供空 `POSTGRES_TEST_URL` 时运行 |
| Milvus/BGE/DeepSeek 集成 | 未形成自动化套件 | 多数测试以 Mock 隔离；真实服务结果不能由当前套件证明 |
| 智慧档案端到端 | 未实现 | P04 之后才具备完整业务闭环 |

## 4. Mock 与隔离

- Router 测试使用 FastAPI `dependency_overrides` 替换 Session 或 Runtime。
- 外部 Milvus、Embedding、DeepSeek 调用用 `monkeypatch` / `Mock` 隔离。
- 测试 SQLite 是临时或内存数据库；不会修改当前业务 PostgreSQL。
