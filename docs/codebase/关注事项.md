# 关注项

## 1. 优先风险

| 优先级 | 问题 | 证据 | 影响 | 建议 |
|---|---|---|---|---|
| 高 | 进度事实分散在 README、学习计划、设计、实施与验收文档 | `README.md`、`LEARNING_PLAN.md`、`docs/implementation/` | 后续开发可能把历史制度 Agent 当成当前能力 | 当前状态以 handoff、DEC-022 和实际代码为准；历史资料只在归档目录追溯 |
| 中 | 历史表和 `POLICY` 行仍存在 | Alembic 历史、`app/models/agent.py` | 维护者可能误以为旧 API 仍可用，或误清理历史线程 | 保持旧 API 404，并持续测试档案入口拒绝 POLICY、项目删除不误清理无项目线程 |
| 中 | SQLite 与 PostgreSQL 的测试语义不同 | `tests/`、`app/db.py` | SQLite 通过不代表 PostgreSQL 方言行为 | 需要 PostgreSQL 的场景继续使用显式可选测试 |
| 中 | 同步解析、BGE、Chroma 和 DeepSeek 运行在请求线程 | `app/services/archive/`、`app/services/infrastructure/ai_models.py` | 大文件或并发会阻塞请求 | V1 保持同步并记录耗时；验证后再决定队列/异步任务 |

## 2. 结构与类划分债务

| 项目 | 现状 | 风险 | 建议 |
|---|---|---|---|
| 归档模型 | 已拆为 `project.py`、`archive.py`、`checklist.py`、`archive_audit.py` | 新模型若绕过 `app.models` 公共导出，可能造成导入入口不一致 | 新业务代码优先从 `app.models` 导入；仅在模块内部需要专用常量/枚举时直接导入对应模块 |
| `archive/documents.py` | 项目文档上传、解析状态与档案投影共用同一业务域 | 继续扩展时职责可能膨胀 | 保持 Router→Service，并只在出现真实重复时继续拆分 |
| `archive/final_chunks.py` / `archive/retrieval.py` | 正式索引写入与读取分离，底层共用 Chroma 客户端 | 范围过滤若分叉会产生越权风险 | 新入口必须复用服务端 `user_id + kb_id + CONFIRMED` 范围规则 |

## 3. 安全

| 风险 | 类别 | 现有缓解 | 缺口 |
|---|---|---|---|
| Bearer Token 泄漏 | A07 身份认证失败 | JWT 用途/有效期、认证会话与资源所有权校验 | 本地学习环境不替代生产密钥和终端治理 |
| 外部模型数据 | N/A（业务数据边界） | 需求限制仅虚构/脱敏资料 | 尚无上传内容自动敏感信息检测 |
| 跨存储删除 | N/A | 旧文档状态补偿与精确 Chroma 过滤 | 进程崩溃后仍需人工/后续恢复策略 |

## 4. 性能与扩展

| 问题 | 证据 | 规模化风险 | 建议 |
|---|---|---|---|
| 同步重任务 | `archive/documents.py`、`infrastructure/ai_models.py` | Web worker 被解析或模型推理占满 | 在 AV1 验收后基于实测决定后台任务 |
| SQLite Checkpoint | `app/agents/archive/runtime.py` | 多实例/并发写入不适合 | 只有部署需求出现时再迁移 Checkpoint 存储 |
| 外部依赖超时仍非跨组件总预算 | `infrastructure/ai_models.py`、`archive/retrieval.py` | 外部故障可能拉长一轮请求 | 保持固定客户端超时与只重试连接/超时；总预算按真实证据另立项 |

## 5. 高变更区域

当前高变更区域是 `app/services/archive/`、`app/agents/archive/`、`app/services/agent/archive_*`、`app/services/infrastructure/ai_models.py` 和设计文档。已删除的 `app/services/rag/`、`app/agents/admin/` 及更早历史路径不应作为当前实现依据。

## 6. 已确认的 P04 分层基线

1. 智慧档案模型已拆为 `project.py`、`archive.py`、`checklist.py`、`archive_audit.py`；表名、字段、约束和 `app.models` 公共导入入口不变，因此不需要数据库迁移。
2. 当前公开业务入口统一从 `/projects` 进入并执行 `Router → Service`；旧知识库、普通 Chat 和制度 Agent Router 已下线。
