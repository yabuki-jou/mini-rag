## 补丁 1:API §3.2(分页、Idempotency-Key)+ §8(问答参数)+ §12(待确认事项)

### 1.1 分页(替换 §3.2 中 [ASK USER] 分页条目)

```text
- 列表使用 `page`（从 1 开始）和 `page_size`；默认 `page=1`、`page_size=20`、最大
  `100`。所有列表统一追加 `id DESC` 作为次级排序，见本小节排序规则。
```

### 1.2 Idempotency-Key(替换 §3.2 中 [ASK USER] 条目,删除原草案描述)

```text
- 第一版不引入 `Idempotency-Key` 请求头。写操作幂等性由以下机制共同保证：
  聚合 `expected_version` 乐观锁、`archive_operations` 单 RUNNING 操作锁、
  重复确认幂等返回、上传 `file_hash` 去重、删除失败复用未完成操作。
  网络自动重试仅限连接失败/超时一次，且不得重复写入成功结果、Chunk 或审计。
```

### 1.3 问答检索参数(替换 §8 中两处 [ASK USER])

`archive-retrieval` 小节:

```text
`top_k` 固定为默认 `5`、最大 `10`。没有依据返回 `200` 与空 `items`。
```

`archive-questions` 小节:

```text
服务先用 PostgreSQL 获取正式 `document_id` 集合，再以服务器注入的
`user_id + project_id + kb_id + document_id` 过滤 Milvus，最后调用 DeepSeek。
内部检索固定 `top_k=5`（与 archive-retrieval 默认一致），候选 Chunk 按相似度
降序截取前 5 条作为回答上下文；不设相似度硬阈值，检索范围由 top_k 控制。
回答只能使用检索 Chunk 的原文；每条引用必须返回文件名、定位和摘录。
问题长度限制为 `1..2000` 个字符。
验收可复现性：12 个固定问答用例在固定 top_k、固定 BGE 模型与固定分块配置下
结果可复现，引用正确率按需求文档 12.3 判定。
```

## 补丁 2:API §7 confirm 小节(重复 confirm 幂等)

在 `POST .../confirm` 小节末尾追加:

```text
幂等语义：文档已为 `CONFIRMED` 且 `expected_version` 与当前版本匹配时，重复
`confirm` 幂等返回 `200` 当前档案，不重新生成 Final Chunk、不新增成功审计；
版本不匹配返回 `409 VERSION_CONFLICT`。`confirm` 允许的状态为
`PENDING_CONFIRMATION`、`PENDING_RECONFIRMATION` 与幂等返回的 `CONFIRMED`；
其他状态返回 `409 CONFIRM_NOT_ALLOWED`。
```

将:

```text
每个归档文档只保留一个当前、可重建的解析快照。它不是档案版本历史；重新解析替换
快照前必须先满足状态和操作锁规则。
```

替换为:

```text
每个归档文档只保留一个当前、可重建的解析快照。它不是档案版本历史。V1 中普通解析

迁移策略，不属于本期范围。
```

## 补丁 9:数据库 §6.9(内部操作记录生命周期)+ §12(验收清单)

### 9.1 §6.9 末尾追加生命周期说明

```text
操作记录生命周期（控制表增长）：

- `DELETE` 类：未完成（`RUNNING`/`FAILED`）记录必须保留至删除完成（部分唯一索引
  保证至多一条）；删除成功后 `archive_documents` 物理删除，操作记录随 ON DELETE
  CASCADE 清理，最终不残留。
- 非 DELETE 类（`PARSE`/`SUGGEST`/`INDEX`）：每次操作进入终态
  （`SUCCEEDED`/`FAILED`）后，删除该文档同类型更早的终态记录，仅保留最新一条；
  文档删除时随级联清理。因此每文档每非删除类型至多保留一条历史记录，表规模有界
  （约等于文档数 × 3 + 未完成删除操作数）。
- `RUNNING` 记录不清理；服务重启后按 `(operation_status, updated_at)` 索引扫描
  恢复未完成操作。
```

### 9.2 §12 数据库验收清单追加一条

```text
- 每份文档每非删除操作类型至多保留一条终态记录；未完成 `DELETE` 记录保持
  `visibility_blocking` 直到删除完成。
```
