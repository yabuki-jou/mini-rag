# FR-042 本地后端闭环问题排查与解决方案

## 问题原因

两次不通过都来自验收脚本把工具调用次数写得比正式契约更严格，并非后端回答、引用或存储失败：

1. 正式契约是单轮最多两个工具调用，不要求每轮恰好一次。
2. 没有成功工具调用时，服务端必须返回固定无依据拒答；因此无据题零工具是允许的安全路径。

## 排查方法

1. 先确认回答状态、正文和引用是否正确。
2. 再比较需求、架构、API 与测试中的工具预算原文。
3. 把“固定评测集的期望路径”和“公开产品允许路径”分开，不能用前者覆盖后者。
4. 每次重跑前检查 Chroma 与文件残留为零，避免旧数据影响结果。

## 解决方案

- 目录回答：必须新增 `1..2` 条目录工具记录。
- 有据回答：必须新增 `1..2` 条证据工具记录，并返回同文档引用。
- 无据拒答：允许新增 `0..2` 条证据工具记录；零工具时仍必须使用固定拒答和空引用。
- 所有已执行工具必须为 `COMPLETED`，摘要继续执行脱敏字段检查。
