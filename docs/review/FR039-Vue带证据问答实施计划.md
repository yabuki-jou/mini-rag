# FR-039 Vue 项目内检索与带证据问答实施计划

## 1. 目标与边界

本切片把后端已经实现的 FR-039 正式档案检索与带证据问答接入相邻 Vue 工作台。用户可以在当前项目的正式档案范围内执行原文检索，也可以提交单轮问题，并直接查看后端返回的回答状态、回答正文和来源证据。

本切片不修改后端公开 API、数据库结构、检索算法、Top-K 规则、Reranker、回答 Prompt 或证据充分性判定；不实现聊天历史、流式输出、文档预览、审计查询、删除能力或业务运行时多 Agent。前端不得根据检索片段自行生成答案，不得补造引用，也不得把相似度或重排分数解释为已确认的固定阈值。

## 2. 已确认契约

- `POST /projects/{project_id}/archive-retrieval`
  接收 `query` 与 `top_k`（1～10，默认 5），返回 `items`、`requested_top_k` 和 `returned_count`。每条证据包含 Chunk、文档、文件名、位置类型、起止位置、原文摘录、向量分数和可选重排分数。
- `POST /projects/{project_id}/archive-questions`
  接收 `question`，返回 `answer_status`、`answer` 和 `citations`。状态只有 `ANSWERED` 与 `REFUSED_NO_EVIDENCE`。
- 身份、项目和知识库范围均由 Bearer 会话及后端项目依赖注入；前端请求体不提交用户或知识库标识。
- 正式检索与问答范围只包含当前项目的 `CONFIRMED` 档案。待确认、待重新确认、人工无证据字段及其他项目内容不得作为回答依据。
- 问题或查询文本长度为 1～2000；诊断检索 Top-K 为 1～10。

## 3. 实现步骤

1. 在前端类型层新增 FR-039 专用请求、证据、检索响应和问答响应 DTO，避免复用旧知识库工作台的 Milvus 类型。
2. 在 API 层新增正式档案检索与问答两个方法，精确调用后端项目路由并原样提交契约字段。
3. 在 Pinia Store 保存当前项目的最近一次检索结果与问答结果：
   - 切换项目时清空旧项目的结果并使在途请求失效；
   - 同一能力连续请求时只接受最后一次响应；
   - 过期请求的成功或失败均不得覆盖当前项目状态或污染当前错误提示；
   - 不从诊断检索结果拼装问答结果。
4. 新增带证据问答面板并接入工作台 `questions` 路由：
   - 主区域提交单轮问题并显示服务端回答状态和正文；
   - `ANSWERED` 逐条展示文件名、位置、摘录及诊断分数；
   - `REFUSED_NO_EVIDENCE` 原样展示服务端拒答且不显示伪造引用；
   - 独立的原文检索区支持查询和 1～10 的 Top-K，显示实际返回数量和证据；
   - 明确说明分数仅供检索诊断，不作为前端证据充分性阈值。
5. 更新工作台说明文字，使 FR-039 页面不再落入占位组件；其他尚未实现入口保持现状。

## 4. TDD 与验收

### RED

先增加并实际运行失败测试，至少覆盖：

- API 的精确 URL、方法和请求体；
- Store 的结果保存、项目切换清理、最后一次请求优先及过期错误隔离；
- 问答面板的输入校验、回答状态、引用定位、拒答无引用和检索 Top-K；
- 工作台 `questions` 路由接入真实面板，且进入页面不会自行发起问题或生成答案。

### GREEN

只实现使上述行为通过的最小前端代码，不修改后端生产 RAG、公开契约或扩大到 FR-040/041。

### 最终验证

1. 运行新增与相关前端测试。
2. 运行前端完整测试、`typecheck` 和 `build`。
3. 运行后端 FR-039 相关测试、完整测试和 `compileall`。
4. 在 Chroma、Embedding、Reranker 和 DeepSeek 均可用后，使用真实 `5173/api -> 8000 -> PostgreSQL/Chroma/DeepSeek` 链路验收：
   - 当前项目已确认原文可以检索并返回正确定位；
   - 有据问题只依据当前项目原文回答并返回正确引用；
   - 无据、仅待确认有据和仅其他项目有据的问题均拒答且引用为空；
   - 合同签订日期问题按 `DOCUMENT_DATE` 语义回答并引用正确合同；
   - 刷新页面后不伪造本地历史，重新提交仍以服务端结果为准。
5. 精确清理临时用户、项目、文档、原文件和向量数据，再更新交接文档。

## 5. 停止条件

若实现需要改变公开 API、核心数据库结构、正式档案范围、证据充分性规则、检索排序或模型 Prompt，Luna 停止扩大修改并交回主 Agent 重新评审。
