# ADR — P14 阶段 C.1：双排序诊断与受控决策

**Status:** Implemented（C.1 诊断已完成，P14 质量门槛未通过）
**Date:** 2026-09-01
**Deciders:** 学习者（本人）+ AI 协作者

> 本 ADR 是 C.1 的历史决策记录；2026-09-02 的 C4-A Top-30 独立授权、执行状态和后续门控以
> [P14-C2 检索质量优化方案](P14-C2-检索质量优化方案.md)为准，不改变本 ADR 的 C.1 结果。
> C4-B 查询表达也已在 2026-09-02 由用户单独授权并完成复验；该授权来自 C2 台账，不改变本 ADR
> 对 C.1 诊断边界的历史记录，且 C4-C 仍未获授权。

## Context

P14 固定问题集包含 8 个有据问题、2 个无据问题和 2 个项目隔离问题。通过门槛为：

```text
有据命中 >= 7/8
无据拒答 = 2/2
项目隔离 = 2/2
```

阶段 A 的纯稠密诊断显示标准证据通常已进入候选集，但阶段 C 的完整候选从 `8/8` 降为
`7/8`。当时只能确认“没有可冻结阈值”，不能确认问题发生在 Chroma 召回还是 Reranker
排序，因此在没有归因前不得继续修改 Chunk、查询、模型或评测集。

## Decision

只增强 P14 固定集运行器的脱敏诊断，复用健康的本机 `8000` 服务；不启动临时 `8002`，
不改变检索行为、模型、候选池、Chunk 或阈值。

诊断同时保留阶段 A 的 dense 字段语义和阶段 C 的 Reranker 字段：

- dense：`expected_candidate_rank`、`expected_distance`、`nearest_incorrect_distance`、
  `distance_gap`、`nearest_candidate_distance`、`incorrect_candidate_kind`；
- Reranker：有据题的候选池数量、Chroma Top-10 是否包含标准证据、重排排名、重排分数和
  与最强错误候选的分数差；
- 无据题：候选数量、最高 Reranker 分数、该候选对应的 dense distance，以及原有
  `nearest_candidate_distance`。

安全输出只使用稳定题目序号和数值，不输出问题正文、标签原始 ID、文件名、路径、摘录、
资源标识或 Token。

## Action Items

- [x] 在健康本机 `8000` 上完成双排序诊断，并保持检索行为不变。
- [x] 保留 dense 旧字段，补充有据题和无据题的独立 Reranker 诊断字段。
- [x] 完成固定集复验、清理核对和决策归因；确认未冻结阈值且不进入 P12。

## Options considered

| 方案 | 决定 |
|---|---|
| 不做归因直接修改检索 | 拒绝，依据不足且范围风险高 |
| 双排序诊断后再决策 | 采纳，低风险且不改变线上行为 |
| 直接扩评测集、换模型或改召回 | 拒绝，属于产品/范围重新授权 |

## Outcome

C.1 已完成 TDD、定向回归、完整回归和真实固定集复验。真实运行复用健康的本机 `8000`：

- `GROUNDED-07` 的 `candidate_count=10`，但标准证据的 dense 与 Reranker 排名均为空，
  直接证实该题是 Chroma Top-10 召回缺失；
- 两个无据题的最高 Reranker 分数为 `0.981258`、`0.696090`，对应候选的 dense distance
  为 `0.289213`、`0.334844`；
- 聚合结果仍为有据 `7/8`、无据 `0/2`、隔离 `2/2`，不存在可冻结的检索阈值；
- 验收临时账号、项目、文档和内部知识库已清理为零，P12 不得开始。

详细阶段证据见[检索质量问题分析与改进策略](检索质量问题分析与改进策略.md)，当前任务见
[P14-C2 检索质量优化方案](P14-C2-检索质量优化方案.md)。

## Decision gates

1. 标准证据未进入完整 Chroma Top-10：只记录“召回缺失”。Chunk 粒度调整会影响 P01
   冻结的定位和 Final Chunk ID，属于产品/范围决策，必须重新授权。
2. 标准证据进入 Top-10 但 Reranker 排序或分数间隔失败：只记录“重排不可分”。改变
   查询表达或更换模型会突破当前“唯一例外=本地 `BAAI/bge-reranker-base` 重排”，必须重新授权。
3. 扩展或修改固定评测集会改动 AV1-P02 已冻结的 Ground Truth，必须重新授权并重新冻结
   验收门槛 `1.0`。
4. 发现范围外候选：优先按安全缺陷处理，不进入质量优化。
5. 只有同时达到 `>=7/8`、`2/2`、`2/2`，才可冻结独立重排阈值并进入 P12。

上述分支不是已批准的 Reranker 后续步骤；当前 ADR 只批准诊断、复验和如实记录。
