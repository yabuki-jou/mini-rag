# P14-D3 固定候选集 Reranker 质量—延迟联合验证方案

## 1. 状态与目的

- **状态：方案已制定；D3-A/B 已执行，D3-C 按门控未执行**。
- 本方案用于在同一份冻结的 Top-30 候选集上，对 `BAAI/bge-reranker-base` 与 `BAAI/bge-reranker-large` 进行单变量质量对比；只有质量门通过后，才进入延迟优化。
- 本方案不改变正式配置、正式 Collection、公开接口、评测问题集或既定检索变量。所有实验均属于独立实验范围。

## 3. 冻结变量与实验边界

以下变量在 D3-A、D3-B 及质量通过前保持不变：

- Embedding：`bge-base-zh-v1.5`，768 维。
- 数据：独立实验 Collection；不得切换正式 Collection。
- 检索字段：`evidence_values`。
- Chroma 候选池：Top-30（K=30）。
- Reranker 查询模式：`c4_a`。
- 评测集：AV1-P02 固定 12 题。
- 公开结果：最多返回 Top-10。
- 不修改 `.env`、默认配置、正式 Collection、Chunk/窗口、查询表达或评测集。

实验输出必须脱敏，不得保存或打印 Token、密码、完整制度正文、完整隐藏推理或其他秘密。

## 4. 分阶段执行方案

### D3-A：冻结候选与长度核验

1. 对固定 12 题生成并持久化脱敏的 Top-30 候选快照，记录候选顺序、`document_id`/Chunk 标识的脱敏值、过滤条件和模型配置摘要。为同候选复放所需的原始 query/chunk 文本只允许留在内存，或写入被 `.gitignore` 覆盖的临时回放文件；不得写入受版本控制的文档或结果。
2. 在同一快照上统计真实 query、候选文本的 token 长度分布、最大值与超长比例；不因长度结果自动调整 `max_length`。
3. 核验 base 与 large 读取完全相同的候选快照，确认其他变量未漂移。持久化结果只保留固定题号、rank、score、哈希与配置摘要；实验后删除原始回放文件。

### D3-B：同候选 K=30 的 base/large 单变量 A/B

1. 仅替换 Reranker 模型，分别运行 base 与 large；候选、顺序、查询表达、阈值、评测集和公开 Top-10 限制全部相同。
2. 分别记录公开覆盖式召回、严格诊断、无据拒答、项目隔离、统一阈值可用性、纯 Reranker P95、峰值内存和失败样本。
3. 先判定质量门，再判定性能门；不得用延迟结果替代质量结果。
4. 若 large 质量未通过，立即终止 large 后续优化，不运行 D3-C 的 large 参数搜索；base 同理。质量失败不得通过更换查询表达、阈值、候选池或评测集规避。

### D3-C：仅质量通过后的单变量延迟优化

D3-C 只有在对应模型通过质量门后才可执行。每轮仅改变一个变量，并在固定质量集上复验质量：

1. 候选 K：依次测试 K=20、K=15；不得把任何预估值写成实测。
2. 推理参数：单独测试 `max_length`；具体值须由 D3-A 长度核验结果和当轮授权确定。
3. 推理后端：单独测试 ONNX 或 OpenVINO INT8；不得与 K 或 `max_length` 同轮改变。
4. 任一轮质量不再满足门槛，回滚该轮变量并停止该分支；记录回滚前后的脱敏配置与指标。

## 5. 验收门槛与分支决策

### 质量门

- 公开覆盖式召回至少 `7/8`。
- 无据拒答必须 `2/2`。
- 项目隔离必须 `2/2`。
- 存在一个统一候选阈值，可使固定集同时满足上述三项质量门；不得为单题单独调阈值。

D3 仅记录阈值可行性与分数间隔，不修改配置、不正式冻结阈值。正式阈值标定与冻结仍属于 C4-C，需单独授权。

### 性能门

- 纯 Reranker P95 不高于 `8000 ms`。
- 完整链路 P95 仅实测记录，不作为本轮质量通过条件；需注明测量范围、并发与环境。

### 决策表

| 质量 | 纯 Reranker 延迟 | 决策 |
|---|---|---|
| 通过 | ≤8000 ms | 可记录为候选方案，并按需做单变量优化或收口 |
| 通过 | >8000 ms | 质量保留；标记延迟风险，只有在后续授权下进入 D3-C |
| 不通过 | 任意 | 立即终止该模型分支，不得进行延迟优化 |

large 延迟超过风险线只能触发性能分支，不能推导出 large 质量失败。若 base 与 large 均未达到质量门，D3 结束并回到问题分析台账；不得自动启动 C4-C。
