# FR-042 项目档案助手文档导航

本目录保存 FR-042 的需求与设计评审、阶段验收、真实模型评测，以及 P153548/世界银行术语问题的诊断材料。内容包含历史计划、试验数据边界和未通过结果，属于项目过程证据，不是对外展示用的项目简介。

当前状态以[项目交接快照](../../stage/handoff.md)为准；稳定产品与范围决策以[决策台账](../../decisions.md)为准；当前需求和实现契约以[需求说明](../../design/需求说明.md)、[接口设计](../../design/接口设计.md)及[FR-042 MVP 实施计划](../../implementation/FR042-项目档案助手MVP实施计划.md)为准。以下评审和实验文档用于追溯，不取代这些事实源。

## 建议阅读顺序

1. 先读交接快照和决策台账，了解当前阶段、授权与限制。
2. 再读 FR-042 MVP 实施计划及需求、架构、数据库和 API 设计。
3. 查设计评审时，读本目录下四份评审记录；它们按评审发生时记录结论，不代表当前代码状态。
4. 查实现或真实资料质量时，按下表选择对应验收或诊断记录，并保留各自的评估边界。
